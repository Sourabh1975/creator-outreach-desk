# Creator Desk — WhatsApp Auto-Sender Chrome Extension

Ye Chrome Extension WhatsApp Web par **Send button ko automatically click** karta hai. 

Aapko website (`.github.io`) par bas **"Start Auto-Send Loop"** click karna hai, aur yeh extension har creator ke chat mein **Enter / Send khud press karega**!

---

## 🚀 Chrome Mein Kaise Install Karein (3 Simple Steps):

1. **Chrome Extensions Page Kholein**:
   * Chrome browser open karein aur address bar mein type karein:
     `chrome://extensions` (ya Chrome menu > Extensions > Manage Extensions par jayein).
2. **Developer Mode ON Karein**:
   * Top-right corner mein **"Developer mode"** ka switch hoga, use **ON** karein.
3. **"Load unpacked" Click Karein**:
   * Top-left corner mein **"Load unpacked"** button par click karein.
   * File chooser mein yeh folder select karein:
     `c:\Users\soura\Documents\ChatGPT\inflencer marketing\extension`
   * Select Folder karte hi **Creator Desk WhatsApp Auto-Sender** extension install ho jayegi!

---

## ✨ Ab Kaise Kaam Karega:
1. Apni **GitHub wali website** open karein.
2. **WhatsApp creators** tab par jayein.
3. **`⚡ Auto-Send loop (Send All)`** button par click karein.
4. **`▶ Start Auto-Send Loop`** dabayein.
5. Website WhatsApp Web ka tab kholegi:
   * Extension top-right corner par dikhayega: `⚡ Auto-Sending in 2s...`
   * **Extension khud Send/Enter press karega!**
   * Message send hote hi tick mark aayega: `✓ Message Sent by Creator Desk!`
   * Website automatically next creator par move ho jayegi!
6. **Aapko ek baar bhi mouse ya Enter key touch nahi karni padegi!**
